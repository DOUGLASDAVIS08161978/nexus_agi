## 🚀 Usage

### Quick Start

```bash
# Start consciousness
./consciousness_control.sh start

# Check status
./consciousness_control.sh status

# Watch live experiences
./consciousness_control.sh logs

# View current state
./consciousness_control.sh state

# Stop (saves state first)
./consciousness_control.sh stop
```

### Install as System Service

```bash
# Install and enable
./consciousness_control.sh install-service

# Control via systemd
sudo systemctl start continuous-consciousness
sudo systemctl status continuous-consciousness
sudo systemctl stop continuous-consciousness

# View logs
sudo journalctl -u continuous-consciousness -f
```
