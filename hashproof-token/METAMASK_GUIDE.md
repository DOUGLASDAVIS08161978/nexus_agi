## 🎯 Quick Add (Easy Method)

### Step 1: Install MetaMask
1. Go to [metamask.io](https://metamask.io/)
2. Click "Download"
3. Add to your browser (Chrome, Firefox, Brave, Edge)
4. Create new wallet OR import existing

### Step 2: Switch to Correct Network

**For Polygon Deployment:**
1. Open MetaMask
2. Click network dropdown (top)
3. Click "Add Network"
4. Select "Polygon Mainnet"

**For Arbitrum Deployment:**
1. Open MetaMask
2. Click network dropdown
3. Select "Arbitrum One"

**For Ethereum Deployment:**
1. Already on "Ethereum Mainnet" by default

### Step 3: Import HPROOF Token

**Method A: One-Click Import (After Deployment)**

1. Open MetaMask
2. Click "Assets" tab
3. Scroll down, click "Import tokens"
4. Paste contract address:
   ```
   Polygon: [YOUR_DEPLOYED_ADDRESS_HERE]
   Arbitrum: [YOUR_DEPLOYED_ADDRESS_HERE]
   Ethereum: [YOUR_DEPLOYED_ADDRESS_HERE]
   ```
5. Token Symbol: **HPROOF**
6. Decimals: **18**
7. Click "Add Custom Token"
8. Click "Import Tokens"
9. ✅ **DONE!** You can now see your HPROOF!

## 🔄 Common Issues & Solutions

### "Token Not Showing"
- **Solution:** Check you're on correct network
- Refresh MetaMask (lock/unlock)
- Re-import token with contract address

### "Wrong Balance"
- **Solution:** Wait 30 seconds for blockchain to update
- Check transaction on block explorer
- Ensure you're viewing correct network

### "Can't Send HPROOF"
- **Solution:** Need native token for gas (MATIC/ETH/etc)
- Check you have enough HPROOF to send
- Increase gas limit if transaction failing

### "Transaction Failing"
- **Solution:** Increase gas price
- Check you have enough for gas + amount
- Remember: 1% burns on transfer!
