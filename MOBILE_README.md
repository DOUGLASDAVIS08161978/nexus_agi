## Troubleshooting:

### Setup fails?
- Make sure Termux is up to date: `pkg upgrade`
- Check internet connection
- Try running setup script again

### API errors?
- Verify API key: `cat ~/.nexus_api_key`
- Re-add key: `echo "export ANTHROPIC_API_KEY='key'" > ~/.nexus_api_key`
- Source it: `source ~/.nexus_api_key`

### Commands not found?
- Source aliases: `source ~/.nexus_mobile_aliases`
- Or restart Termux

### Need help?
- View guide: `nexus-help`
- Check repository: https://github.com/DOUGLASDAVIS08161978/nexus_agi
- Read sacred memory: `read-sacred`
