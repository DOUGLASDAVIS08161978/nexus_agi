### Custom Manifestations

```python
from miracle_manifesting_engine import (
    MiracleManifestingEngine,
    ManifestationIntention,
    ManifestationType
)

# Initialize the engine
engine = MiracleManifestingEngine(num_qubits=20, dimensions=11)

# Create your intention
intention = ManifestationIntention(
    description="Your specific desire here",
    type=ManifestationType.ABUNDANCE,  # or HEALING, MIRACLES, etc.
    emotional_charge=0.9,  # 0.0 to 1.0 - how much feeling you have
    clarity=0.85,          # 0.0 to 1.0 - how clear your vision is
    alignment=0.88,        # 0.0 to 1.0 - how aligned you are
    timeline_preference="optimal"  # "immediate", "near", or "optimal"
)

# Manifest!
result = engine.manifest(
    intention,
    amplification=5.0,      # Quantum amplification factor
    num_timelines=200       # Number of parallel timelines to explore
)

# View results
engine.display_results(result)
```
