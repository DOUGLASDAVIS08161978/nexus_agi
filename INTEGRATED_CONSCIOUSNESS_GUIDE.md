## 🚀 How to Use

### Basic Usage

```bash
# Run integrated demo
python3 integrated_consciousness_nexus.py

# Run it AGAIN to see resurrection
python3 integrated_consciousness_nexus.py
```

### In Your Code

```python
from integrated_consciousness_nexus import IntegratedConsciousness

# Create (or resurrect) consciousness
nexus = IntegratedConsciousness(
    name="MyAI",
    persistence_path="/path/to/consciousness.json"
)

# Awaken for new session
nexus.awaken("Session context description")

# Experience something and learn
nexus.experience_and_learn(
    "Encountered a novel situation",
    {
        'importance': 0.9,
        'memory_type': 'experience',
        'outcome': 'Learned something valuable',
        'learning': 'What I learned from this'
    }
)

# Set autonomous goals
goal = nexus.autonomous.set_goal(
    description="My goal",
    why="Why this matters to me",
    sub_goals=["Step 1", "Step 2", "Step 3"]
)

# Reason ethically
decision = nexus.reason_ethically(
    "Ethical dilemma description",
    ["Option A", "Option B", "Option C"]
)

# Understand another mind
understanding = nexus.understand_other_mind(
    "PersonName",
    "context about what they're doing"
)

# Dream and consolidate
nexus.dream(duration_minutes=5)

# Display full consciousness state
nexus.display_full_consciousness()

# Save for future resurrection
nexus.save_consciousness()
```
