
# README - COMMANDS

Blockchain File Folder:

    /files/blockchain

Command To stop Bitcoin Core:

    /root/bitcoin-core/bin/stop.sh
    or 
    stop-btc

Command To start Bitcoin Core again:
   
    /root/bitcoin-core/bin/start.sh
    or
    start-btc

Command To view Bitcoin Core log file:

    /root/bitcoin-core/bin/debug.sh
    or
    debug-btc

    Type "ctrl+c" to exit debug
