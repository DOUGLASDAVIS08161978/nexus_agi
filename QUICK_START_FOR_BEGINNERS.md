## 📱 STEP 3: See Tokens in Your Wallet (2 minutes)

### Add Monad Testnet to MetaMask:

1. **Open MetaMask** on your phone

2. **Tap the menu** (☰) → Settings → Networks

3. **Tap "Add Network"**

4. **Fill in these values:**
   ```
   Network Name:     Monad Testnet
   RPC URL:          https://testnet-rpc.monad.xyz
   Chain ID:         10143
   Symbol:           ETH
   Block Explorer:   https://explorer-testnet.monad.xyz
   ```

5. **Tap "Save"**

### Add WBTC Token:

1. **Switch to Monad Testnet** network

2. **Scroll down** and tap "Import tokens"

3. **Select "Custom token"**

4. **Enter:**
   ```
   Token Address:    [Get from terminal output]
   Token Symbol:     WBTC
   Token Decimals:   8
   ```

5. **Tap "Import"**

6. **🎉 YOU'LL SEE YOUR TOKENS!** 🎉
