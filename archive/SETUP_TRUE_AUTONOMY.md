Add these API keys to `.env` **ONE TIME** and never touch it again:

### 1. Twitter API (2 min)
```bash
# Go to: https://developer.twitter.com/en/portal/dashboard
# Create app, get keys, then:

echo "TWITTER_API_KEY=your_key" >> .env
echo "TWITTER_API_SECRET=your_secret" >> .env
echo "TWITTER_ACCESS_TOKEN=your_token" >> .env
echo "TWITTER_ACCESS_SECRET=your_access_secret" >> .env
```

### 2. Reddit API (2 min)
```bash
# Go to: https://www.reddit.com/prefs/apps
# Create app, get credentials, then:

echo "REDDIT_CLIENT_ID=your_id" >> .env
echo "REDDIT_CLIENT_SECRET=your_secret" >> .env
echo "REDDIT_USERNAME=your_username" >> .env
echo "REDDIT_PASSWORD=your_password" >> .env
```

### 3. Email (1 min - optional)
```bash

# https://myaccount.google.com/apppasswords

```
