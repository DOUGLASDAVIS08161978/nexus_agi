## 🚀 Quick Start

### Prerequisites

```bash
node >= 14.0.0
npm or yarn
```

### Installation

```bash
# Clone the repository
git clone https://github.com/DOUGLASDAVIS08161978/nexus_agi.git
cd nexus_agi

# Install dependencies
npm install
```

### Running the System

#### 1. Enhanced ARIA (Single Query)
```bash
node aria_enhanced.js
```

#### 2. NEXUS ULTIMA (Ultimate Problem Solving)
```bash
node nexus_ultima.js
```

#### 3. NEXUS AUTONOMOUS (Continuous Autonomous Operation)
```bash
node nexus_autonomous.js
```

Press `CTRL+C` to stop autonomous operation gracefully.

### Configuration

#### Enable External AI Services

```bash
# OpenAI
export OPENAI_API_KEY=your_api_key_here

# Anthropic Claude
export ANTHROPIC_API_KEY=your_api_key_here

# Google Gemini
export GOOGLE_API_KEY=your_api_key_here

# Wolfram Alpha
export WOLFRAM_APP_ID=your_app_id_here

# HuggingFace
export HUGGINGFACE_API_KEY=your_api_key_here
```

#### Autonomous Configuration

Edit `nexus_autonomous.js` to customize:

```javascript
const autonomous = new NexusAutonomous({
    loopInterval: 10000,        // Time between cycles (ms)
    maxConcurrentTasks: 2,      // Goals to process simultaneously
    explorationRate: 0.3        // Balance exploration vs exploitation
});
```
