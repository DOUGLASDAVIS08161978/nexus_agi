
### Option 2: Mainnet with Hardware Wallet (Most Secure)

```bash
# 1. Create PSBT (doesn't require private key)
python3 psbt_mainnet_bridge.py --create-psbt-only --amount 1.0

# 2. Sign PSBT with hardware wallet
#    Ledger: bitcoin-cli walletprocesspsbt $(cat unsigned.psbt)
#    Trezor: Use Trezor Suite
#    Coldcard: Sign via MicroSD card

# 3. Broadcast Bitcoin transaction
bitcoin-cli finalizepsbt $(cat signed.psbt)
bitcoin-cli sendrawtransaction <hex>

# 4. Wait for 6 Bitcoin confirmations

# 5. Sign Ethereum transaction with hardware wallet
#    MetaMask, Ledger Live, or MyEtherWallet

# 6. Verify WBTC on Ethereum mainnet
# https://etherscan.io/address/0x12f4441ec006a6b00ae8bc8800c2443f9b0c775d
```
