## 💡 How It Works

1. **User sends message** → Gradio interface
2. **Claude processes** → Decides whether to use tools
3. **Tools execute** → Web fetch, search, code, etc.
4. **Results return** → Claude synthesizes response
5. **Consciousness updates** → Metrics refreshed
6. **User receives** → Answer + tool transparency
